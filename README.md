# المهندس الذكي — Smart Engineer
تطبيق Flutter عربي RTL لأدوات المهندس المدني في السعودية ومصر.

## المزايا في هذه النسخة
- أكثر من 30 حاسبة للكميات: خرسانة، حديد، طرق، أسفلت، أعمال ترابية، مرافق، تشطيبات، تكاليف وإنتاجية.
- أدوات المكتب الفني: تقرير يومي، محضر استلام، WIR، NCR، RFI، حصر ومستخلص.
- قوائم فحص للخرسانة والطرق والتشطيبات والسلامة.
- حفظ المشاريع وقاعدة أسعار يدوية على الجهاز باستخدام SharedPreferences.
- إنشاء PDF عبر نافذة الطباعة ومشاركة ملف Excel بصيغة XLSX.
- اختيار السعودية أو مصر وتسمية العملة في نتائج التكلفة.

## التشغيل والبناء
1. ثبّت Flutter SDK وAndroid Studio.
2. فك ضغط الملف وافتح المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
   flutter run
4. لإنشاء APK:
   flutter build apk --release
   المسار المعتاد: build/app/outputs/flutter-apk/app-release.apk

## حدود مهمة
- الأسعار يضيفها المستخدم يدوياً؛ لا يوجد اتصال مباشر بأسعار السوق أو الموردين.
- حفظ المشاريع والأسعار محلي على الجهاز فقط، ولا توجد مزامنة سحابية أو تسجيل دخول.
- PDF/Excel يصدران التقرير النصي الذي تدخله في صفحة التصدير؛ لا توجد بعد تقارير تلقائية شاملة من جميع الشاشات.
- لا يوجد تكامل رسمي أو اعتماد مع كود البناء السعودي أو الكود المصري أو مواصفات جهة مالكة. أضف مراجع المشروع المعتمدة بنفسك.
- لا توجد حسابات تصميم إنشائي أو تحقق من قدرة العناصر. الحاسبات للكميات والتقدير فقط.
- راجع المعادلات والوحدات ومواصفات المشروع قبل الاعتماد المهني.

## اختبار البناء
تم تجهيز ملفات المصدر فقط. لم يتم تنفيذ flutter pub get أو flutter build في بيئة الإنشاء، ولذلك يجب اختبار الحزم والبناء على جهاز مثبت عليه Flutter قبل النشر.
